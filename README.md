# recont-node-web

RECONT NODE 新HPサイト(静的サイト)

## 概要

社長提供の素案HTMLを取り込んだ、RECONT NODEの新HPサイトです。ビルド不要の静的HTML1枚構成で、GitHub Pagesで公開します。

## 公開URL

https://hitomin-git.github.io/recont-node-web/

## 構成

- `index.html` — サイト本体(HTML/CSS/JSをすべて内包)

## デプロイ方法

mainブランチへのマージ後、GitHub Pages(Settings > Pages、Source: Deploy from a branch / main / root)が自動的に反映します。ビルドステップは不要です。
